# PowerBI-BUILDS
Interactive Power BI dashboard analyzing sales, revenue, profit, customers, and product performance using Excel data.## Dataset Description
# Dataset Description
The dataset contains business sales information including:
- Customer details
- Product data
- Sales orders
- Regional performance
- Revenue and profit metrics

The data was imported from Excel and transformed in Power BI for analysis and visualization.
## Dashboard Description

This interactive Power BI dashboard provides insights into:
- Total revenue and profit
- Product performance analysis
- Customer contribution
- Revenue by sales channel
- Geographic revenue distribution
- Year-wise sales comparison

The dashboard includes filters and slicers for dynamic analysis.
